The four rules we followed

What it does

Only eligible people vote, only once, in secret, and nobody can quietly change the result.

01

Eligible voters only

Only IDs on the approved roll can log in. Everyone else is turned away at the door.

02

One person, one vote

The moment a ballot is cast, that Voter ID is locked. No second tries.

03

Secret ballot

Choices are stored apart from voter records, so nobody can trace a vote to a person.

04

Receipt codes

Every voter gets a unique receipt code as proof their ballot was sealed.

05

Live turnout, sealed results

Watch turnout in real time. Results stay hidden until the admin closes the polls.

06

Audit log

Every poll event is recorded: opened, closed, ballots cast. Never the choices.

How it works

How an election runs

01

Admin sets up

Add posts, candidates and the voter roll, then open the polls.

02

Voters cast

Log in, pick one candidate per post, review and lock the ballot.

03

Results unseal

When the admin closes polls, winners and vote counts appear.
